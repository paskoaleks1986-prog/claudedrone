~/ardupilot/          ← ArduPilot SITL
~/ardupilot_gazebo/   ← плагин для Gazebo

1. install ardupilot
git clone https://github.com/ArduPilot/ardupilot.git
cd ardupilot
git submodule update --init --recursive

Важнейший этап: установка зависимостей (Python, компиляторы)
# Этот скрипт настроит переменные окружения и установит нужные пакеты
Tools/environment_install/install-prereqs-ubuntu.sh -y

Перезагрузи терминал, чтобы подтянулись пути (PATH)
source ~/.bashrc

WARN!!!
sim_vehicle.py не найден в PATH. Добавляем вручную:
bashecho 'export PATH=$PATH:$HOME/ardupilot/Tools/autotest' >> ~/.bashrc
source ~/.bashrc
which sim_vehicle.py

Переходим в директорию коптера и собираем проект (первая сборка долгая)
cd ArduCopter
sim_vehicle.py -w
flag -w refresh default drone schema. for prj not use

2. run 
sim_vehicle.py -w --console


команды
GUIDED  Переводит дрон в управляемый режим (необходим для взлета по команде).
arm throttle Снимает защиту и запускает моторы.
takeoff [высота]  Взлет на указанную высоту в метрах.
mode RTL  Автоматический возврат в точку взлета и посадка.
mode LANDПосадка в текущей точке.statusВыводит текущее состояние всех параметров MAVLink.

Пример смены режима через MAVROS
ros2 service call /mavros/set_mode \
  mavros_msgs/srv/SetMode \
  "{custom_mode: 'GUIDED'}

3 install gazebo plagins
cd ~
git clone https://github.com/ArduPilot/ardupilot_gazebo.git

cd ~/ardupilot_gazebo
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=RelWithDebInfo
make -j4

Устанавливаем gstreamer:
bashsudo apt install libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev

Плагин собран успешно! Добавляем пути:
bashecho 'export GZ_SIM_SYSTEM_PLUGIN_PATH=$HOME/ardupilot_gazebo/build:${GZ_SIM_SYSTEM_PLUGIN_PATH}' >> ~/.bashrc
echo 'export GZ_SIM_RESOURCE_PATH=$HOME/ardupilot_gazebo/models:$HOME/ardupilot_gazebo/worlds:${GZ_SIM_RESOURCE_PATH}' >> ~/.bashrc
source ~/.bashrc

ls ~/ardupilot_gazebo/models
Видим готовые модели — iris_with_ardupilot

gz sim ~/ardupilot_gazebo/worlds/iris_runway.sdf -r
-r flag run simulation! same you push play in Gazebo layout

Теперь подключаем SITL к этому Gazebo. Открой новый терминал:
bashcd ~/ardupilot/ArduCopter
sim_vehicle.py -v ArduCopter -f gazebo-iris --model JSON --console

Разбор:

-f gazebo-iris — используем модель iris для Gazebo
--model JSON — SITL общается с Gazebo через JSON протокол

if gazebo has no pic, this can fix if GeForce GPU
sudo nvidia-settings --assign CurrentMetaMode="nvidia-auto-select +0+0 { ForceFullCompositionPipeline = On }"
