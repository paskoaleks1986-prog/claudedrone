## Что такое MAVROS и зачем он нужен

Вспомни архитектуру из roadmap:

```
ROS2 ноды          MAVROS          ArduPilot SITL
(наш код)    ←——————————————→    (полётный контроллер)
             переводчик
```

**Проблема:** ROS2 и ArduPilot говорят на разных языках.

- ROS2 использует свои типы сообщений: `geometry_msgs/PoseStamped`, `sensor_msgs/Imu` и т.д.
- ArduPilot говорит на **MAVLink** — это бинарный протокол, разработанный специально для дронов. Не JSON, не HTTP — свой формат байт, очень компактный и быстрый.

**MAVROS** — это ROS2 нода-переводчик. Она сидит посередине и делает два дела:

```
ArduPilot                    MAVROS                    Наш код
─────────                   ────────                  ─────────
MAVLink пакет   ──────→   переводит   ──────→   ROS2 топик
"высота 1.5м"              в PoseStamped         /mavros/local_position/pose

ROS2 топик      ←──────   переводит   ←──────   MAVLink пакет
/mavros/cmd/arming         в CMD_COMPONENT_ARM   "arm throttle"
```

*Аналогия:* ты приехал в Японию и не знаешь японский. MAVROS — это твой переводчик. Ты говоришь ему "взлети на 2 метра" на русском (ROS2), он переводит это на японский (MAVLink) и передаёт пилоту (ArduPilot).

## Ключевые топики MAVROS которые будем использовать

**Читаем** (ArduPilot → наш код):

| Топик | Что содержит |
|---|---|
| `/mavros/state` | armed, mode, connected |
| `/mavros/local_position/pose` | позиция XYZ + ориентация |
| `/mavros/imu/data` | данные IMU |
| `/mavros/battery` | заряд батареи |

**Пишем** (наш код → ArduPilot):

| Топик | Что делает |
|---|---|
| `/mavros/setpoint_position/local` | лети в эту точку XYZ |
| `/mavros/setpoint_velocity/cmd_vel` | лети с этой скоростью |
| `/mavros/cmd/arming` | включить/выключить моторы |
| `/mavros/set_mode` | сменить режим (GUIDED, LOITER...) |

## Почему не просто MAVProxy?

MAVProxy — это консоль для человека. Ты вводишь руками `takeoff 2`. MAVROS — это для **программного** управления. Твой Python скрипт публикует в топик, MAVROS переводит, ArduPilot исполняет. Никакого человека посередине.
