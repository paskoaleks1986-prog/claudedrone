# docs/notes/

> Working notes, experiment log, and tool observations for ClaudeDrone development.
> Рабочие заметки, дневник экспериментов и наблюдения по инструментам в процессе разработки ClaudeDrone.

Здесь хранятся неформальные записи — то, что не стало финальной документацией, но помогает понять ход мыслей и выводы из экспериментов.

This folder contains informal records — things that didn't become final documentation, but capture reasoning and conclusions from real experiments.

---

## Что сюда класть / What goes here

- `2024-03-fritzing-notes.md` — наблюдения при работе с Fritzing: слои, экспорт, проблемы / observations while using Fritzing: layers, export issues
- `2024-04-ros2-first-run.md` — первый запуск ROS 2 на RPi: что сработало, что нет / first ROS 2 run on RPi: what worked, what didn't
- `gazebo-troubleshooting.md` — решения типичных проблем с Gazebo / common Gazebo issues and fixes
- `sensor-calibration-log.md` — результаты калибровки VL53L0X, TF-Luna / calibration results for distance sensors
- `ideas.md` — необработанные идеи и гипотезы / raw ideas and hypotheses

**Не класть сюда / Do NOT put here:** финальные технические спецификации (→ `docs/`), код (→ `software/`, `firmware/`)
