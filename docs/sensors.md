## TF-Luna

Используется дважды с разными задачами:

**#1 — горизонтальное сканирование**
- Установлен на сервопривод SG90, вращается 180°
- Даёт 2D-профиль окружающего пространства
- Данные → ESP32 → RPi → внешний PC (SLAM)

**#2 — удержание высоты**
- Направлен вертикально вниз
- Измеряет высоту над полом
- Данные → PID-регулятор в ESP32 → FC (SBUS)

Диапазон: 0.2–8 m | Частота: до 250 Hz | Интерфейс: UART 115200, 8N1

→ [Полная документация](components/tf-luna/README.md)

## VL53L0X × 6

Шесть ToF-сенсоров расположены по периметру рамы (через каждые 60°).  
Дают сферическое поле обнаружения препятствий вокруг дрона.

Все 6 подключены к одному шине I²C через мультиплексор TCA9548A — каждый на отдельный канал (адреса не конфликтуют).

## PMW3901 — Optical Flow

Сенсор оптического потока. Работает как мышь: считывает движение поверхности под дроном и вычисляет скорость X/Y. Используется для удержания позиции в горизонтальной плоскости без GPS.

## I²C Bus Map

```
ESP32 (I²C master)
 └── TCA9548A (0x70)
      ├── CH0 → VL53L0X (front)
      ├── CH1 → VL53L0X (front-right)
      ├── CH2 → VL53L0X (back-right)
      ├── CH3 → VL53L0X (back)
      ├── CH4 → VL53L0X (back-left)
      ├── CH5 → VL53L0X (front-left)
      └── CH6 → PCA9685 (PWM driver)
```
